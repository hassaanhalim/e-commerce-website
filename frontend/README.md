# E-commerce-Web

Premium shoe-store frontend built with React, TypeScript, Vite, React Router, localStorage-backed state, and a shared admin/customer UI system.

## Run locally

```bash
npm install
npm run dev
```

## Build and check

```bash
npm run build
npm run lint
```

## Demo access

- Admin: `admin@shoestore.com` / `Admin123`
- Customer: `customer@shoestore.com` / `Customer123`

## Notes

- Data is stored in `localStorage` for the current frontend-only phase.
- The app includes storefront, customer account, and admin portal routes.
